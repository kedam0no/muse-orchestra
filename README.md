# muse-orchestra
クラウド型AI（Muse）を指揮者にして、パソコンの中のローカルAIたちを話し言葉で管理する運用パターン。外出先からアプリで指示できて、現在iPhoneとWindowsの間で実運用中。alpha版。 / Muse Orchestra — a pattern where a cloud AI (Muse) conducts the local AIs on your PC through plain spoken instructions. You can direct them from an app while you're out; currently running live between an iPhone and Windows. Alpha.
